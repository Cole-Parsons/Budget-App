# Budget App Plan

## Must haves
- [ ] Spending and income (enter an amount, date, catagory, note)
- [ ] Categories (rent, food, gas, custom)
- [ ] Monthly budgets (category limits)
- [ ] Charts(Pie charts, where money is going & line graph of money spent over time)
- [ ] Monthly summary (total in, total out, what saved)
- [ ] search filter (find transactions by date, catagory, amount.)

## Nice to have
- [ ] Alerts (warning when getting close to budget)
- [ ] recurring bills (auto add rent and subscriptions each month)
- [ ] CSV import, Upload bank statements instead of typing everything
- [ ] Saving goals (500$ for a trip with progress bar)
- [ ] Login and accounts so each user only sees their own data
- [ ] Dark mode and mobile friendly layout (stretch)

## Stretch
- [ ] Bank connection with plaid. Pull transactions in automatically, plaid free sandbox
- [ ] Spending predictions "At this rate youll spend $X on food this month"

## Technologies

Language - Python
Main Frameworks - Custom Tkinter (frontend)
